# J.A.R.V.I.S. Multi-Platform AI & Voice OS

Full-featured deployment of J.A.R.V.I.S. on Hugging Face Spaces:
- 🌐 Futuristic Cyber HUD Web OS & Live Voice Interface
- 🤖 Telegram Voice & Admin Bot
- 🎙️ PyTgCalls Multi-Group VC Music & Video Live Streaming Engine
- 🧠 Multi-Model AI with Free Tier Failover (Nemotron, DeepSeek, Qwen)

### Hugging Face Space Secrets Configuration:
Add these in **Space Settings > Variables and secrets > New secret**:
- `TELEGRAM_BOT_TOKEN`
- `OPENROUTER_API_KEY`
- `BOT_OWNER_ID`
- `TELEGRAM_API_ID`
- `TELEGRAM_API_HASH`
- `TELEGRAM_SESSION_STRING`
- `CARTESIA_API_KEY`
